# MonoStyle Web Frontend

Frontend en React (Vite + TypeScript + Tailwind CSS) para la gestión del taller de motocicletas MonoStyle.

## Requisitos
- Node.js (v18+)
- Backend de Spring Boot corriendo en `http://localhost:8080`

## Instalación y Ejecución
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```
3. Abrir `http://localhost:5173` en tu navegador.
